Do not let August fade

Hi Parent,

This is Moyo from the InstinctHub Kids Can Code team. Over the next eight Thursdays I am sending you one practical tip a week about raising a child who builds things with a computer instead of only watching things on it. No sales pitch in the middle of the tips. Just the things I would tell a cousin.

The first one is time-sensitive, which is why it comes first.

When a child stops using a skill for a few weeks, the skill does not sit still. It fades. Research on the school holiday gap puts the loss at roughly a quarter to a half of a year's maths gains when nothing is practised, and coding behaves like maths, not like reading. A child who wrote a working program in August can be staring blankly at the same screen by October.

The good news from the memory research is that short and spaced beats long and rare. Five minutes every few days keeps a skill alive better than one long catch-up session.

This week's tip

The 15-minute Saturday re-run

This Saturday morning, ask your child to open a program they built recently (a summer class project, a game, anything) and run it again. Then ask them to change one small thing: a colour, a name, a number in the rules. That is all. Fifteen minutes. Repeat next Saturday.

You are not teaching. You are keeping the door open.
